## Why

VPN 内的多台设备需要一个打开即用的临时内容共享板，用于粘贴文本和传输文件。现有方案已经明确删除设备同步、实时推送和账号体系；现在需要一个单实例 MVP 规格，把条目生命周期、认证边界、预览安全和配置持久化一次定死。

## What Changes

- 新增 Go 单体服务，同时提供 Web UI 和 REST API。
- 支持文本条目和文件条目：发布、倒序列表、查看、复制、下载、预览和删除。
- 支持多文件上传；每个文件成为独立条目，不引入上传批次。
- 条目创建时固化过期时间；保留策略只允许 1 小时到 7 天，没有永久条目。
- 文本默认上限 1 MiB；文件大小和总容量由服务器配置限制。
- 使用共享密码登录，密码以 Argon2id 哈希保存；修改密码后所有 Session 失效。
- 浏览器原生预览只允许安全内联类型；未知、不一致和活跃内容类型强制或引导下载。
- 本地文件系统存储条目内容和元数据；通过 staging 目录和原子重命名保证条目可见性。
- Web 可修改保留策略和密码；监听、路径、容量和限制只能由服务器配置修改。
- 提供 Docker 部署，`/config` 与 `/data` 挂载为持久卷。
- 不实现 CLI、Desktop 客户端、WebSocket、轮询、自动发现、P2P、剪贴板同步、用户账号、数据库或 Redis。

## Capabilities

### New Capabilities

- `shared-items`: 文本和文件条目的发布、列举、读取、预览、下载、删除、TTL 与文件系统一致性行为。
- `access-control`: 共享密码认证、Session 生命周期、密码修改后的凭证失效和 API 访问边界。
- `web-ui`: 首页共享列表、手动刷新、文本/文件发布、安全预览、设置弹窗和登录界面行为。
- `runtime-configuration`: 配置 schema、运行时可变设置、原子持久化和服务器静态边界。

### Modified Capabilities

- 无。当前项目没有既有规范。

## Impact

- 新增 Go 服务、REST API、Web UI、本地存储层、TTL Worker、配置管理器和 Docker 部署产物。
- `/data` 是条目内容和元数据的唯一持久化位置；`/config` 保存服务配置。
- API 是外部程序和 AI Agent 的唯一编程入口；没有实时推送协议，客户端通过手动 GET 刷新。
- 运行时修改会重写 `config.yaml`，管理员手写注释不保证保留。
